# Sitio web de CEDEINCO

Sitio corporativo estático preparado para GitHub Pages.

## Estructura

- `index.html`: página principal.
- `css/styles.css`: estilos visuales y diseño responsive.
- `js/app.js`: menú móvil, animaciones y lightbox de galería.
- `img/`: imágenes optimizadas en formato WebP.

## Publicar con GitHub Pages

1. Sube todos los archivos y carpetas conservando la estructura.
2. En el repositorio abre `Settings`.
3. Selecciona `Pages`.
4. En `Build and deployment`, elige `Deploy from a branch`.
5. Selecciona la rama `main` y la carpeta `/ (root)`.
6. Guarda los cambios.
